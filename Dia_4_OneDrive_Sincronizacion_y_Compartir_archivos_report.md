# OneDrive no sincroniza y cómo poder compartir archivos

1. OneDrive no sincroniza
   - Es el fallo donde los archivos locales de tu PC no se actualizan o suben a la nube de Microsoft
   - Suele ocurrir por falta de espacio o archivos con nombres o rutas muy largas
   - También suele suceder cuando la aplicación de OneDrive perdió la sesión

2. Compartir archivos
   - Es la funcionalidad clave para la colaboración que permite enviar enlaces a otros usuarios.
   - Otorgando permisos específicos (Lectura o Edición), sin necesidad de adjuntar archivos pesados por correo

# Cómo se interconectan con otras herramientas
   - Windows Server y Redes: este concepto equivale a las carpetas compartidas en red (Shared Folders)
y asignación de permisos NTFS/Compartidos.
   - OneDrive: Traslada esa misma necesidad de almacenamiento centralizado y control de accesos a la nube, 
Permitiendo que el administrador supervise dónde se guardan los datos corporativos de los usuarios.

# Práctica guiada paso a paso

1. Paso A: Abre tu navegador, ingresa a Outlook.com, inicia el iniciador de aplicaciones (los puntitos de la esquina superior).
2. Paso B: Una vez abierto, busca cualquier archivo o crea un documento para practicar (nuevo en Word o Excel)
3. Paso C: Haz clic sobre ese archivo (busca los 3 puntitos ... al lado del archivo), selecciona Compartir (Share)
4. Paso D: Observa la ventana que se abre; te permite elegir como quieres compartirlo (por ejemplo, "Cualquier persona con el vinculo puede ver" o restringido a personas especificas)
Cambia los permisos entre "Permitir la edicion o solo Lectura", y fijate como funciona el control de acceso en la nube.
