# M365 Documented Practice

# Prácticas de Microsoft 365 en la nube

##  Propósito del repositorio
Este repositorio documenta prácticas de Microsoft 365 en la nube (Office.com y servicios gratuitos).  
El objetivo es mostrar evidencia clara y reproducible de mi aprendizaje,  
integrando conocimientos y administración de identidades en la nube.

##  Contenido
- Ejercicios prácticos en Word, Excel, PowerPoint web.
- Gestión de archivos y permisos en OneDrive.
- Simulación de colaboración en Teams.
- Documentación de conceptos clave de administración en M365.
- Evidencia en capturas y pasos reproducibles.

##  Cómo usar este repositorio
Cada carpeta corresponde a un bloque de práctica (ejemplo: `M365_Day1`, `M365_Day2`).  
Dentro encontrarás:
- Archivos creados en Office.com.  
- Capturas de pantalla como evidencia y explicaciones.    

##  Propósito final
Este repositorio forma parte de mi portafolio IT.  
Busca demostrar habilidades prácticas en Microsoft 365 y su relación con administración de sistemas  
y redes, preparando el camino hacia roles de IT Support y IT Administration.
